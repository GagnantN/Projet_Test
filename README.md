Pour utiliser le projet testing :

- Installer dans le terminal du projet cloner : pip install flask
- A la racine du projet dans le terminal : python app.py
- Aller sur ce lien : http://127.0.0.1:5000

  Projet lancé !!

Pour lancer les tests dans la machine.

- Installer pytest dans le terminal du projet : pip install pytest
- Avec Visual Studio Code cliquer sur lancer le fichier test_app.py
- Si tout est en vert dans la console alors tous les tests sont passés.

  Félicitations !!
